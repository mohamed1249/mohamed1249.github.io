  • The chapter’s core idea is that unsupervised learning is powerful, but it is not “let the machine discover the truth.” It is still shaped by human choices.
  • My personal note: Before PCA, remove or question irrelevant features. Because PCA looks for directions of high variance, not “business importance.” So an irrelevant feature with huge variance can still dominate the components and mislead the analysis.
  • A few strong ideas from this chapter:
    • Unsupervised learning searches for hidden structure when predefined labels don’t exist.
    • PCA = dimensionality reduction: compress many correlated features into fewer components while preserving as much information as possible.
    • No variation = no information.
    • PCA effectively tries to find a more informative “rotation” of the data.
    • High variance is only a proxy for importance, not importance itself.
    • Principal components can be hard to interpret; forcing catchy meanings onto them can create fake stories.
    • In clustering, scaling matters. A large-scale variable can dominate distance calculations.
    • Clustering has no single correct answer. Different algorithms, distance measures, scaling choices, and numbers of clusters can produce different groupings.
    • So ironically, unsupervised learning still requires a lot of supervision.
  • And that opening quote is excellent: “If you mine the data hard enough, you can find messages from God.” Basically: if you search long enough for patterns, you will eventually find something that looks meaningful—even when it isn’t.
  • The cleanest takeaway for me: Hidden patterns are discovered partly by the algorithm and partly created by the choices of the analyst.
